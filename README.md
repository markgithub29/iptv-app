# IPTV App (React)

A TV-friendly IPTV dashboard built with React and Vite. It includes a live player placeholder, channel browsing, category filters, search, favorites, and a recently watched section.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Build for production

```bash
npm run build
npm run preview
```
